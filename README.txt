ABDULLAHI AUWALU PORTFOLIO

Files:
- index.html: website content
- style.css: design and responsive layout
- script.js: mobile navigation, current year, and WhatsApp link

Before publishing:
1. In index.html, replace your-email@example.com with your real email.
2. In index.html, replace +234 YOUR PHONE NUMBER with your WhatsApp number.
3. In script.js, replace 2348012345678 with your WhatsApp number using digits only (country code first; no + or spaces).
4. Replace the sample projects with real projects you have built. Do not claim sample projects as paid client work.

Publish with GitHub Pages:
1. Sign in to GitHub and create a new public repository named abdullahi-portfolio.
2. Upload index.html, style.css, and script.js into the repository's main/root folder.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a few minutes and open the website address shown on the Pages settings screen.

This is a static portfolio website; it does not process payments or automatically find clients.
